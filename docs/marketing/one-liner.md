# Truenex Memory — One-Liner

> **Query, don't re-read.**

---

## La Definizione

Truenex Memory è il **memory layer locale che dà ai tuoi agenti AI una memoria persistente**. Invece di rileggere 60 file di documentazione a ogni sessione (50.000+ token sprecati), l'agente fa una query semantica e riceve solo i 5 chunk rilevanti (~500 token).

**Local-first. Privacy-first. Agent-first.**

---

## Per Chi

Sviluppatori che usano agenti AI (Claude Code, Codex, Cursor) e sono stanchi di:
- Rispiegare il contesto a ogni nuova chat
- Sprecare migliaia di token in letture inutili
- Vedere la context window dell'agente satura di rumore

---

## In Pratica

```
Senza Truenex Memory:
  Agente apre la chat → legge 60+ file docs → 50.000 token → 2 minuti → inizia

Con Truenex Memory:
  Agente apre la chat → memory_search("contesto") → 500 token → 0.3s → inizia
```
