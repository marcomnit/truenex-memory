# Prompt Unico — 9 Immagini Mancanti per Truenex Memory

Genera 9 immagini, una alla volta, nell'ordine elencato. Dopo ogni immagine chiedimi se procedere con la successiva.

**Contesto:** Truenex Memory è un memory layer locale per agenti AI di coding. Sostituisce la rilettura integrale della documentazione con query semantiche mirate, risparmiando migliaia di token a sessione. Local-first, privacy-first, open source.

**Stile globale:** palette ciano (#00BCD4), viola (#7C4DFF), bianco, nero. Moderno, tech, pulito.

Sulla scrivania, una pila enorme di fogli (documentazione, log, note) che l'agente sta cercando di leggere tutti insieme. Orologio sul muro con lancette che girano veloci.
